# Skali stack glyph — color and dark appearance studies

Mode: built-in imagegen. Each independent edit attached the selected [flat stack glyph](../skali-icon-concepts-v2-flat/03-stack-glyph.png) as its reference.

Brief: develop the selected simple stack symbol in alternative colors, with matching dark variants that move the color onto the symbol itself. Keep the three-piece geometry and generous spacing. These are concept studies; existing application assets have not been changed.

Generated images in displayed order:

1. [teal / default](01-teal-default.png)
2. [teal / dark](02-teal-dark.png)
3. [indigo / default](03-indigo-default.png)
4. [indigo / dark](04-indigo-dark.png)
5. [ember / default](05-ember-default.png)
6. [ember / dark](06-ember-dark.png)

All six original 1254 × 1254 raster outputs are preserved. Prompt hex values are art-direction targets, not guaranteed exact output pixel values. A final production master should use shared vector geometry for precise matching across appearances.
